# 분석 요약

## 분석 범위
- 기간: 2025-01 ~ 2026-07 (19개월)
- 기준: 유효 주문(배송중, 배송완료, 결제완료, 배송준비) — 취소/환불 제외

## 핵심 지표

| 지표 | 값 |
|---|---|
| 총 매출(유효 주문 기준) | 약 15.9억 원 |
| 취소·환불 손실액 | 약 2.5억 원 |
| 취소·환불율 | 약 13.5% |
| 재구매 고객 비율(2회 이상 주문) | 87.1% |
| 상위 20% 고객의 매출 비중 | 42.6% |

## 카테고리별 특징
- 매출 1위: 생활가전 (약 4.0억 원, 전체의 25%) — 취소·환불율도 가장 낮은(12.7%) 안정적 카테고리
- 취소·환불율이 높은 카테고리: 문구(15.7%), 홈인테리어(14.6%), 반려동물(14.3%)

## 고객 특징
- 30대가 매출 기여도 1위(약 6.3억 원, 39%), 1인당 평균 구매액도 최고(169만 원)
- 성별 간 매출/객단가 차이는 미미함
- 서울이 매출 1위 도시(약 4.6억 원)로, 2위 부산(약 1.7억 원) 대비 뚜렷하게 편중

## 결제수단별 특징
- 휴대폰결제(14.8%), 간편결제(14.4%)의 취소·환불율이 계좌이체(11.5%) 대비 높음

## 계절성
- 11~12월에 매출이 뚜렷하게 상승 (12월이 연중 최고, 2월 대비 약 2.3배)

## 후속 분석 제안
- RFM 세그먼트 분석
- 코호트 기반 리텐션 분석
- 취소·환불 발생 원인 상품/조건 심층 분석
