# 담당 역할 및 기여 내용



# 담당자 B

## 1. 데이터 병합 및 파생 컬럼 계산

- **주문 상세 금액 계산**: order_items의 quantity와 unit_price를 곱해 item_amount 컬럼을 생성하고, 계산값을 assert로 직접 검증했습니다.
- **데이터 병합**: order_items를 기준으로 orders, products, customers 데이터를 순차적으로 병합하여 분석용 통합 데이터를 구성했습니다. 병합 전후 행 수와 결측치를 비교해 데이터 누락이 없음을 검증했습니다.

## 2. 핵심 지표 및 집계 함수 개발

- **핵심 지표 계산 함수 작성**: 전체 주문 수, 총 주문 수량, 총 주문 금액, 평균 주문 금액, 주문 상태별 건수를 계산하는 `calculate_core_metrics()` 함수를 작성했습니다.
- **카테고리별·월별 매출 집계**: `calculate_category_sales()`, `calculate_monthly_sales()` 함수를 작성해 카테고리별 매출 순위와 월별 매출 추이를 산출했습니다.
- **Streamlit 재사용 구조화**: 반복되는 계산 로직을 `src/analysis.py`에 함수 단위로 정리하여, 다른 팀원이 화면(app.py)에서 바로 가져다 쓸 수 있도록 했습니다.

## 3. 코드 리팩터링 및 협업 개선

- **공통 로딩 함수 재사용**: 초기에는 CSV를 직접 읽는 코드를 별도로 작성했으나, A(담당자 choi)가 만든 `load_all_data()`를 재사용하도록 리팩터링하여 코드 중복을 제거했습니다.
- **고객 정보 병합 추가**: 기존 병합 로직에 customers 데이터를 추가해 도시·성별·나이 정보도 분석에 활용할 수 있도록 개선했습니다.

## 4. AI 코드 단위 검증 및 문서화

- **단위 검증 기록 작성**: 주문 금액 계산, 데이터 병합, 핵심 지표 계산, 로딩 함수 리팩터링까지 총 4개의 기능 단위에 대해 실행 전 예상, 실제 결과, 검증 방법을 기록했습니다 (`docs/code_checks/dydtlsrl/`).
- **분석 결과 문서화**: `docs/analysis_summary.md`에 전체 주문 기준 핵심 지표를 정리하고, A가 작성한 유효 주문 기준 지표와 교차 검증하여 두 결과의 정합성을 확인했습니다.
