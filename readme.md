# 담당 역할 및 기여 내용

## 1. 저장소 및 협업 환경 구축

* **GitHub 저장소 생성 및 권한 관리**: 팀 GitHub 저장소를 생성하고 팀원들을 Collaborator로 등록하여 개발 협업 환경을 구축했습니다.
* **기초 설정 파일 작성**: 프로젝트 안내를 위한 `README.md` 초안과 불필요한 파일 추적을 방지하는 `.gitignore` 파일 생성 및 환경을 설정했습니다.

## 2. 프로젝트 구조 정립 및 의존성 관리

* **공통 프로젝트 구조 준비**: 팀원 간 원활한 개발을 위해 디렉토리 및 파일 구조를 표준화하고 프로젝트 기본 뼈대를 마련했습니다.
* **의존성 패키지 관리**: 프로젝트 실행에 필요한 라이브러리를 `requirements.txt`로 통합 관리하여 팀원 간 개발 환경 일치성을 확보했습니다.

## 3. 형상 관리 및 코드 검증

* **PR 리뷰 및 Merge 지원**: 팀원들이 개별 브랜치에서 작성한 Pull Request(PR)를 리뷰하고 충돌 방지 및 main 브랜치로의 안전한 병합 작업을 진행했습니다.
* **단위 검증 기록 확인**: 코드 통합 시 팀원별 단위 테스트 및 검증 기록의 존재 여부를 점검하여 코드 품질을 유지했습니다.

## 4. 통합 테스트 및 환경 재현성 검증

* **main 브랜치 앱 실행**: 병합된 코드가 작성된 main 브랜치 기준으로 전체 애플리케이션의 정상 동작을 확인했습니다.
* **클린 환경 재현 테스트**: exercise라는 임의의 폴더에 저장소를 git clone한 후 환경 설정부터 애플리케이션 실행까지 전체 프로세스가 원활히 재현되는지 최종 검증했습니다.
